## Sample Assets

Each sample includes:

- Entity configurations
- Ability definitions
- Effect templates
- Tag hierarchies
- Complete C# integration code

## Getting the Samples

Samples are included in the PlayForge package under `Samples~/`.

Import via Package Manager:

1. Open **Window > Package Manager**
2. Find **PlayForge**
3. Expand **Samples**
4. Click **Import** on desired sample
